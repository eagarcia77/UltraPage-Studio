QTI 2.1 Blackboard

Build stable QTI 2.1 ZIP packages for Blackboard Ultra, then reuse the same validated bank for Moodle or Canvas. Convert readable questions without assembling exchange files manually.

Supported question types

MC: Multiple choice TF: True / False FIB: Fill in the blank ESSAY: Essay MA: Multiple answer MATCH: Disabled SA: Not supported by Ultra QTI

Recommended format: begin each question with its type. Use * to mark the correct answer or accepted responses. Leave one blank line between questions. This version supports the Blackboard-documented QTI types MC, MA, TF, FIB, and ESSAY.

Compatibility notes

This version generates a QTI 2.1 package using the structure accepted in Blackboard Ultra testing: imsmanifest.xml at the ZIP root and item files inside items/.

To import, download the generated .zip file and upload it in Blackboard Ultra from Manage Banks using the QTI package import option. Do not rename the extension or compress the XML files separately.

Important: MATCH and SA remain blocked in the Blackboard QTI 2.1 profile. MA is generated with multiple-response cardinality. TF questions preserve their True/False options. Optional QTI responseProcessing is intentionally omitted because Blackboard skips items that include it.

Post-import verification

  1. Import into a sandbox course and wait for the LMS processing result.
  2. Compare the imported question count and question types with the preflight report.
  3. Open every item type and verify prompts, choices, accepted answers, and correct-answer settings.
  4. Confirm points, multiple-answer behavior, Spanish accents, symbols, and line breaks.
  5. Review any import warning or removed-item detail supplied by the LMS.
  6. Complete the assessment in Student Preview before releasing it to students.
